# Walmart Sales Forecasting

This project focuses on forecasting Walmart store sales using historical data, statistical analysis, and machine learning techniques.

## Objectives

* Analyze historical sales patterns.
* Identify factors influencing sales performance.
* Build predictive models to forecast future sales.
* Develop interactive dashboards in Power BI for business decision-making.

## Tools and Technologies

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Power BI
* Git & GitHub

## Project Structure

* Data collection and preparation
* Exploratory Data Analysis (EDA)
* Feature Engineering
* Predictive Modeling
* Dashboard Development

## Results

The project evaluates different forecasting models and visualizes key business insights through interactive Power BI dashboards.
